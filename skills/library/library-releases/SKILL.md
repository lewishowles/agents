# Library releases

Prepare a supported library release or find updates and adoption opportunities in a consuming project.

## Pick your guide

| Job                                        | Guide                                                              |
| ------------------------------------------ | ------------------------------------------------------------------ |
| Prepare and verify a library release       | [Prepare a release](references/prepare-a-release.md)               |
| Survey updates or audit one library deeply | [Survey and adopt updates](references/survey-and-adopt-updates.md) |

The supported packages are `@lewishowles/components`, `@lewishowles/helpers`, `@lewishowles/testing`, `@lewishowles/cli-style`, `@lewishowles/lint-config`, and `@lewishowles/pkg-checks`.

Base release and adoption advice on current package information and the relevant project's code, scripts, and documentation.
