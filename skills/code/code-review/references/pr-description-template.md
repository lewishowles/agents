# PR description template

Copy into a new PR. Pair with [checklist.md](checklist.md) for the review gate itself.

```markdown
## Summary

What this changes and why, in 1-2 sentences.

## What changed

- Bullet the concrete changes, not the diff stat.

## Why

The problem or motivation this solves. Link an issue, discussion, or PROGRESS.md section if one exists.

## Testing performed

- Commands run and their result, or manual steps taken.
- Note anything that couldn't be tested and why.

## Risks

Anything that could break, degrade, or need a follow-up. Say "none" if there genuinely aren't any — don't pad this section to look thorough.
```
